# Memory Diary · Дневник памяти для SillyTavern

**Версия 0.1.9 — пакетная обработка памяти.** Самостоятельное расширение для ручного и автоматического сохранения воспоминаний из ролевых чатов.

## Установка

1. Скачай ZIP и распакуй папку `memory-diary`.
2. Помести папку целиком в `SillyTavern/public/scripts/extensions/third-party/`.
3. Проверь, что `manifest.json`, `index.js`, `core.js`, `api.js` и `style.css` находятся непосредственно внутри `memory-diary`.
4. Перезагрузи страницу SillyTavern. При необходимости включи расширение в менеджере расширений.
5. Открой плавающую кнопку 📚.

Если SillyTavern установлен на сервере или хостинге, папку нужно разместить на том устройстве, где запущена сама Таверна.

## Что есть в прототипе

- Ручная обработка диапазона сообщений по номерам (первое сообщение — №0).
- Ручной диапазон может включать скрытые сообщения, если они всё ещё присутствуют в массиве истории SillyTavern.
- Автоматическая пакетная обработка новых видимых сообщений: по умолчанию каждые 50 новых сообщений анализируется пачка из 50 сообщений.
- Настраиваемая строгость отбора: строгая, сбалансированная или подробная.
- Объединение нескольких сообщений одной сцены в одно воспоминание; модель может вернуть пустой список, если значимых событий нет.
- Хранение книги в метаданных текущего чата (`memory_book_v1`).
- Категории, важность, закрепление, ручная защита, редактирование, отключение и удаление записей.
- Подбор релевантных воспоминаний и добавление их через extension prompt.
- Проверка источников по ID и отпечатку текста; записи с недействительными источниками исключаются из автоматического контекста.
- Экспорт и импорт JSON. Импортированные записи становятся ручными, чтобы не ссылаться на чужие номера сообщений.
- Проверка, что история не изменилась во время обращения к модели.
- Использование текущего API SillyTavern для анализа выбранного диапазона.

## Важные ограничения первой версии

- Автоматическая обработка запускается после заданного количества событий сообщений. События отправки и получения учитываются отдельно, поэтому счётчик может быстрее достигать порога, чем число пар реплик. Рекомендуется сначала тестировать на копии чата.
- Точный состав флагов скрытия может отличаться между версиями SillyTavern. Скрытые сообщения включаются в ручную обработку только если SillyTavern сохраняет их в `chat` и помечает одним из известных флагов (`is_hidden`, `extra.isHidden`, `extra.hidden`).
- Идентификаторы добавляются в `message.extra.memoryBookId`. Существующие сообщения не переписываются по содержимому, но добавление ID требует сохранения истории; в конкретных сборках SillyTavern проверь, что `saveChat()` доступен.
- Автоматическая проверка ветки консервативна: если источник пропал или текст изменился, воспоминание перестаёт попадать в контекст и помечается как устаревшее. Ручные записи не зависят от источников.
- Если удалить/скрыть сообщения штатным механизмом, это расширение не пытается отменять действие. Сначала архивируй диапазон, проверь книгу, затем используй функции скрытия самой Таверны.
- Это ранний прототип, не проверенный на каждой версии SillyTavern и каждом провайдере. Сделай экспорт чата и книги перед первым использованием на важном РП.

## Рекомендуемый безопасный сценарий

1. Создай копию чата.
2. Открой Дневник памяти и выбери небольшой диапазон (5–10 сообщений).
3. Сохрани и проверь записи.
4. Убедись, что подходящие воспоминания отображаются в контексте.
5. Только после теста включай автоматический режим.
6. Перед скрытием больших диапазонов сделай экспорт чата и Дневника памяти.

## Хранилище и приватность

Книга хранится в метаданных текущего чата SillyTavern. При использовании внешнего API выбранный диапазон отправляется этому провайдеру для извлечения воспоминаний. Не отправляй в сторонний API данные, которыми не хочешь делиться.
